# MPC CV LAB — Research plan

## Objective
Investigate whether an ARMv7 VST2 running on the original Akai MPC One with Hakai 3.9.1 can address physical CV/Gate outputs directly, without an intermediate MPC CV Program.

## Verified baseline
The project initiator has routed MIDI generated by a third-party VST2 through an MPC CV Program to Eurorack hardware.

## Open questions
- What Linux interfaces expose the MPC's CV/Gate outputs?
- Does MPC OS use ALSA, a proprietary device, or another hardware abstraction?
- Can a plugin access the same interface safely, or is an MPC CV Program required?

## Read-only inspection on test hardware
Run over SSH; do not modify devices or registers:

```sh
ls -l /dev/snd/
cat /proc/asound/cards
ls -l /dev/ | grep -Ei 'cv|gate|dac|spi|i2c'
```

## Milestones
1. Record device enumeration and research existing VST2 ports.
2. Document candidate interfaces and licensing constraints.
3. Build a minimal plugin proof of concept for a single CV output, only if a safe interface is established.
4. Expand to independent CV modulation channels after hardware validation.

**Status:** No direct CV output from a third-party VST2 has yet been demonstrated by this project.
